01 About

one idea at a time...

I'm Saif Abozaid, a cybersecurity engineer focused on offensive-minded defense: building software that detects, classifies, and explains vulnerabilities before attackers can use them.

My current work combines classical security engineering — dependency scanning, CVSS scoring, applied cryptography — with machine learning: fine-tuning code models (Qwen2.5-Coder, StarCoder2) with QLoRA on datasets like PrimeVul and Juliet to catch vulnerabilities that signature-based tools can't see.

Everything I build ships as working software: CLIs, dashboards, and web apps, all open on my GitHub.

01

DepScan

A two-layer vulnerability detection engine. Layer one queries OSV.dev for known CVEs across project dependencies. Layer two runs a fine-tuned LLM (QLoRA on PrimeVul / CrossVul) over source code to surface unknown vulnerabilities — each finding explained, severity-ranked, and paired with a concrete fix. Ships with a CLI, report dashboard, and time-split evaluation against Juliet to keep false positives honest.
